# personal-budget-tracker
A beginner JavaScript practice project for tracking income, expenses, savings, and financial status.

##Features:
- Enter user's name and monthly income
- Add multiple expenses dynamically
- Calculate total expenses
- Calculate tax and net income
- Find highest and lowest expense
- Calculate remaining balance
- Calculate savings
- Show financial status
- Save data using Local Storage
- Delete Local Storage data using a Delete button
- Return to the homepage using a Back to Homepage button
- Responsive UI

##Technologies Used:
- HTML
- CSS
- JavaScript
- DOM Manipulation
- Event Listeners
- Local Storage
